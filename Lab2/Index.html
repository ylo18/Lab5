1. HTTP: Hyper Text Transfer Protocol
2. HTML: Hyper Text Markup Language

3. For the process of requesting a web page from a web server, your computer contacts a Domain Name System (DNS) server. After that, the unique number that the DNS server returns to your computer allows your browser to contact the web server that hosts the website you requested. Lastly, the web server then sends the page you requested back to your web browser.

4. The difference between a regular tag and an empty tag is that an empty tag only has one tag while a regular tag has two tags.

5. The term white space collapsing means that when a browser comes across two or more spaces next to each other, only one space is displayed. It treats it the same when coming across a line break.
